# Basic Network Sniffer

A simple network sniffer built using Python and Scapy.

## Features
- Captures network packets
- Displays source IP address
- Displays destination IP address
- Displays protocol information

## Technologies Used
- Python
- Scapy

## Installation

```bash
pip install scapy
```

## Run Command

```bash
python sniffer.py
```
